Cum obțin jetonul de acces?
  1. Intrați în GitHub cu contul care are acces la depozitul .
  2. Deschideți formularul pentru jeton — câmpurile principale sunt deja completate.
  3. La „Repository access” alegeți Only select repositories și bifați .
  4. Apăsați „Generate token”, copiați jetonul (începe cu github_pat_) și lipiți-l mai sus.

Dacă contul dumneavoastră este doar colaborator în depozit (nu proprietar), GitHub nu permite jetoanele de acest tip. Folosiți atunci un jeton clasic cu permisiunea „public_repo”.
